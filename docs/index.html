Features

Everything a code map should do

And a few things code maps usually don't.

Graph view

Cards for components, hooks and functions, linked by render, call and prop edges. Expand, collapse, Dim others, zoom and pan.

Group by file

One card per file and one link per pair of files, with how they connect: “renders 2 · calls 1”.

Context links

Each context provider is linked to everything that reads it, even through custom hooks.

Next.js aware

Routes become entry points with their URL. Components get server / client badges, and layouts nest.

Live reload

Save a file and the graph rebuilds. Your selection, open cards and view stay put.

Play flow

Animate a trace from any symbol, level by level or call by call, or view it as a sequence diagram.

Changes since HEAD

New, edited and removed symbols are marked on the graph, with the problems your edits added or fixed.

Open in editor

Right-click a card to jump to its line in VS Code. Compare two similar symbols side by side.

Export

Save as SVG, copy as Mermaid, or save one self-contained HTML page you can pan, zoom and search.

Tour

Answers, not just boxes and lines

Select a card and the detail panel explains it: who uses it, which APIs it hits, which tests cover it, and what looks wrong.

Code health

Filters that find the problems for you

Each filter in the Project panel shows a count. Click it to see only the symbols that match.

Duplicates

Similar code elsewhere, matched by structure, so renamed copies still show up.

Identical

An exact structural twin, where only names or literals differ.

Warnings

Hook dependency bugs, props that defeat memo, prop drilling, lazy() without Suspense.

Unused

Nothing renders, calls or passes it.

Memoized

Wrapped in memo, useCallback or useMemo.

Cycles

Components or functions that render or call each other in a loop.

No tests

No test file imports it, even through barrels and path aliases.

Data

Calls an API, a data-fetching hook or a store itself.

Changes

Review your edits before you commit

In a git repository, the graph is compared with HEAD and kept current as you save, commit or switch branches.

  • Cards show what's new, edited, or affected by a change.
  • Removed symbols and lost links stay visible as dashed red ghosts.
  • The Changes strip counts problems your edits introduced (⚠) or fixed (✓).
  • Select a card to read what it gained or lost: “now renders Streak”.

Usage

Open a folder and go

Use the project menu in the title bar (Ctrl+O, or ⌘O on a Mac), or pass a folder on the command line. Each project remembers its open cards, filters and selection.

# Windows
rendermap.exe C:\path\to\my-app
# macOS
"/Applications/Rendermap.app/Contents/MacOS/rendermap" ~/code/my-app
Build from source

Rust, all the way down

Built with GPUI and tree-sitter. You need stable Rust (2024 edition), plus the MSVC build tools on Windows or the Xcode Command Line Tools on macOS.

$ git clone https://github.com/dalladirosa/react-graph
$ cd react-graph
$ cargo run --release -- path/to/my-app
